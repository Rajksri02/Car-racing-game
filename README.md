# 🚗 Neon Racer (Car Racing Game)

🔗 Live Demo: https://rajksri02.github.io/Car-racing-game/

A modern, fast-paced, browser-based car racing game built entirely with HTML, CSS, and vanilla JavaScript. Dodge oncoming traffic, score points, and try to survive as the speed increases!

## ✨ Features
- **Neon Aesthetic**: Sleek dark mode UI with glassmorphism panels, glowing vector cars (SVG), and a dynamic scrolling parallax road.
- **Particle System**: Real-time dust trails and explosive impact effects on collision.
- **Audio Engine**: Synthesized engine hums, level-up beeps, and crash sounds powered by the Web Audio API (no external sound files needed).
- **Responsive HUD**: Real-time tracking of Score, Level, and Speed.
- **Zero Dependencies**: 100% vanilla JavaScript, HTML, and CSS. No canvas, no WebGL, no game engines.

## 🎮 How to Play
1. Open `index.html` in your browser (or visit the Live Demo).
2. Click **Start Engine**.
3. Use your **Left ⬅️** and **Right ➡️ Arrow Keys** to switch lanes and dodge oncoming enemy cars.
4. The game gets progressively faster every 5 points you score!

## 🛠️ Technologies
- **HTML5**: UI structure and layout.
- **CSS3**: Complex animations (`@keyframes`), transitions, gradients, inline SVGs, and layout.
- **JavaScript (ES6+)**: `requestAnimationFrame` game loop, DOM manipulation, AABB collision detection, and Web Audio API synthesis.
